## 目录结构

| 目录 | 内容 | 来源 |
|---|---|---|
| `sprites/` | 角色/怪物/NPC/物品精灵图 | Shattered Pixel Dungeon |
| `environment/` | 地牢环境瓦片、水面动画 | Shattered Pixel Dungeon |
| `interfaces/` | UI 界面元素（工具栏/状态栏/Buff图标） | Shattered Pixel Dungeon |
| `effects/` | 特效精灵图 | Shattered Pixel Dungeon |
| `music/` | 区域背景音乐 | Shattered Pixel Dungeon |
| `sounds/` | 音效（攻击/拾取/开门/魔法等） | Shattered Pixel Dungeon |
| `splashes/` | 启动画面/标题画面 | Shattered Pixel Dungeon |
| `fonts/` | 像素字体（pixel_font 来自原版，VonwaonBitmap 为自有字体） | Shattered Pixel Dungeon + 自有 |
| `messages/` | 多语言本地化文本 | Shattered Pixel Dungeon |
| `data/` | 数据占位符 | 自有 |
| `shader/` | Godot Shader 程序 | 自有 |
| `sound/` | 音频占位符 | 自有 |

## 自有资源

以下资源不属于 Shattered Pixel Dungeon，为本项目自有：
- `fonts/VonwaonBitmap-*.ttf` — VonwaonBitmap 像素字体（Apache 2.0）
- `shader/` — Godot Shader 程序
- `data/` — 数据占位符
- `sound/.gitkeep` — 音频占位符
